# Shadow Bot

**Shadow Bot** هو بوت تواصل متطور للمجموعات، مستوحى من الشخصية الأسطورية **Cid Kagenou / Shadow** من أنمي *The Eminence in Shadow*. تم إعادة تصميم وتنظيف هذا المشروع ليكون أكثر استقرارًا، سرعة، وكفاءة، مع الحفاظ على مجموعة واسعة من الألعاب، أدوات الوسائط، أنظمة الاقتصاد، وأوامر إدارة المجموعات.

## المميزات الأساسية
- **هوية فريدة وقوية:** تصميم يجمع بين الغموض والقوة المستوحاة من عالم *The Eminence in Shadow*.
- **مكتبة أوامر ضخمة:** يضم مئات الأوامر المصنفة بدقة (ألعاب، وسائل مساعدة، ترفيه، اقتصاد، وإدارة مجموعات).
- **نظام تفاعلي متقدم:** يدعم الردود التفاعلية، أزرار التفاعل، صفحات المساعدة، وأنظمة التهدئة (Cooldown).
- **أمان وموثوقية محسّنة:** فصل تام لبيانات الجلسات وحسابات المستخدمين خارج المستودع العام لضمان الخصوصية والأمان.

## طريقة التشغيل والتثبيت

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/kalix-c/Shadow.git
   cd Shadow
   ```

2. **تثبيت الاعتماديات:**
   ```bash
   npm install
   ```

3. **إعداد ملف الجلسة:**
   ضع ملف حالة الجلسة الخاصة بك داخل مجلد الإعدادات الخاص بالبوت (تأكد من عدم رفعه إلى المستودع العام أبدًا).

4. **تشغيل البوت:**
   ```bash
   npm start
   ```
