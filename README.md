# Shadow Bot

> «أنا شادو؛ أتحرك من خلف الكواليس.»

**Shadow Bot** هو بوت Messenger عربي مستوحى من أجواء *The Eminence in Shadow*، مع الحفاظ على استقلال المشروع عن أي عمل فني رسمي. يجمع البوت بين إدارة المجموعات، قاعدة بيانات JSON، الإحصائيات، الاقتصاد، الألعاب، المهمات والفعاليات التفاعلية.

## الهوية

اسم البوت: **Shadow**
المطور: **محمد الشاوني**
رابط المطور: [Facebook](https://www.facebook.com/profile.php?id=61584561724670)
البادئة الموحدة: **`.` فقط**

## أبرز الأنظمة

| النظام | الوظيفة |
|---|---|
| المساعدة | `.اوامر` أو `.مساعدة` لعرض الأوامر العربية وتقسيمها إلى صفحات |
| الإحصائيات | `.إحصائيات` لعرض نشاط الحديقة والأرقام الشخصية |
| حديقة الظل | `.الحديقة` لعرض الرتبة والتقدم |
| المهمات | `.مهمة_سرية` لإرسال مهمة وجمع الخبرة والمكافآت |
| الاقتباسات | `.حكمة` لاستدعاء اقتباس عشوائي بطابع شادو |
| الألعاب | `.لعبة_الظل` للمبارزات والجوائز والتقدم |
| البادئة | `.البادئة` لعرض البادئة الثابتة ومنع التعارضات |

اكتب `.اوامر الكل` لعرض القائمة الكاملة. بعض الأوامر القديمة ما زالت تملك أسماء بديلة للتوافق، لكن الأسماء الموصى بها للمستخدمين عربية.

## البنية

```text
Shadow/
├── index.js                 # نقطة تشغيل البوت
├── app.js                   # خادم فحص الصحة
├── KaguyaSetUp/config.js    # إعدادات التشغيل والبادئة
├── src/
│   ├── commands/            # الأوامر العربية
│   ├── events/              # أحداث Messenger
│   ├── handler/             # تنفيذ الأوامر والردود والصلاحيات
│   ├── middleware/          # تحميل الأوامر والأحداث
│   ├── database/            # المتحكمات والنماذج
│   ├── listen/              # استقبال الرسائل
│   ├── config/assets.js     # أصول واقتباسات Shadow
│   └── logger/              # سجل آمن مع احتياطي للألوان
├── database/                # ملفات JSON التشغيلية
└── scripts/validate.mjs     # فحص الصياغة والاستيراد
```

## التشغيل

```bash
git clone https://github.com/kalix-c/Shadow.git
cd Shadow
npm ci
npm start
```

يتطلب التشغيل الفعلي تهيئة جلسة Messenger وفق مكتبة تسجيل الدخول المستخدمة. **لا تضع ملفات الجلسة أو الرموز السرية داخل Git**؛ استخدم الملفات المحلية المدرجة في `.gitignore`، ودوّر أي رمز سبق نشره.

## الفحص والاختبار

لفحص صياغة ملفات JavaScript واستيراد الوحدات الأساسية دون تسجيل الدخول:

```bash
npm test
```

ولتشغيل خادم الصحة:

```bash
npm run health
curl http://127.0.0.1:3000/
```

تُرجع نقطة الصحة حالة البوت بصيغة JSON، ولا تتطلب جلسة Messenger.

## مبادئ التطوير

يجب أن تستخدم الأوامر الجديدة البادئة `.`، وتتعامل مع `api` و`event` عبر الواجهات الممررة إليها بدل المتغيرات العامة غير المضمونة. تُحفظ بيانات المستخدمين والإحصائيات في مسارات ثابتة داخل `database/`، وتُستخدم متحكمات الاقتصاد والخبرة المركزية حتى لا تتضارب مكافآت الألعاب والمهمات.

كما يجب أن تبقى الوسائط الخارجية اختيارية؛ فإذا فشل تحميل صورة أو ملصق، يجب أن يعمل الرد النصي بدل انهيار الأمر. لا تُضاف أصول أو اقتباسات محمية بحقوق النشر إلى المستودع دون ترخيص مناسب.
