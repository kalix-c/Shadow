# ⚡ THE EMINENCE IN SHADOW BOT ⚡

> "I am the one who lurks in the shadows to hunt the shadows." — Shadow

**Shadow Bot** هو إعادة تعريف شاملة لبوتات التواصل، مستوحى من شخصية **Cid Kagenou** (المعروف بـ **Shadow**) من أنمي *The Eminence in Shadow*. تم بناء هذا المشروع ليكون "القوة الكامنة" في مجموعاتك، حيث يجمع بين الغموض، القوة التقنية، والترفيه الفائق.

## 🌑 الرؤية الجديدة
لم يعد هذا مجرد بوت أوامر؛ إنه **Shadow Garden** الخاصة بك. تم تنظيف الكود بالكامل، وإعادة هيكلة المشروع ليكون احترافيًا، وتأمين البيانات الحساسة لضمان الخصوصية التامة.

## 🛠️ التحسينات التقنية (Shadow Edition)
- **هيكل SRC منظم:** تقسيم احترافي للمجلدات (Commands, Events, Middleware, Handler) لسهولة التطوير.
- **نظام صلاحيات صارم:** تمييز دقيق بين "أعضاء الحديقة" و"سيد الظل".
- **أداء مُحسن:** معالجة أسرع للأوامر مع نظام تبريد (Cooldown) ذكي.
- **أمان فائق:** استبعاد كامل لملفات الجلسات والبيانات الحساسة من المستودع العام.
- **بادئة جديدة:** البادئة الرسمية هي `!` (تليق بالسرعة والحسم).

## 🚀 البدء السريع

1. **الاستنساخ:**
   ```bash
   git clone https://github.com/kalix-c/Shadow.git
   cd Shadow
   ```

2. **التثبيت:**
   ```bash
   npm install
   ```

3. **الإعداد:**
   ضع ملف `KaguyaState.json` داخل `KaguyaSetUp/`. البوت سيتعرف عليه تلقائيًا كـ "حالة الظل".

4. **الإطلاق:**
   ```bash
   npm start
   ```

## 📜 ميثاق حديقة الظل
- **الغموض:** لا ترفع ملفات الجلسات أبدًا.
- **القوة:** الأوامر تُنفذ بدقة متناهية.
- **الولاء:** المطورون هم أعضاء الحديقة، والمستخدمون هم رعاياها.
